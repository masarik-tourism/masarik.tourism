# مسارك للإنجاز السياحي | MASARIK TOURISM

> **معتمدة وموثقة من الغرفة التجارية المصرية**  
> **تحمل السجل التجاري رقم ٧٨٣٩**

تطبيق ويب حديث ومتجاوب مبني بتقنية **React + TypeScript + Vite + Tailwind CSS** لوكالة **مسارك للإنجاز السياحي (MASARIK TOURISM)** لخدمات التأشيرات والحج والعمرة وحجوزات الطيران والفنادق، بعد إعادة بنائه بالكامل وتحويله من تطبيق أندرويد إلى تطبيق ويب متكامل.

---

## 🚀 التقنيات المستخدمة في المشروع

- **Frontend Framework:** React 19 + TypeScript
- **Bundler & Dev Server:** Vite
- **Styling:** Tailwind CSS v4 (مع دعم كامل للخط العربي `Tajawal` واتجاه النص من اليمين لليسار `RTL`)
- **Icons:** Lucide React
- **Direct Mail Integration:** FormSubmit API مع دعم fallback إلى بروتوكول `mailto:`
- **Payment Portal Simulation:** محاكاة بوابة Paymob مع تأكيد السداد وإصدار المعاملات والربط الفوري بالواتساب
